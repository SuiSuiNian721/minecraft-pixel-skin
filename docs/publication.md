# 发布副本说明

本仓库包含 `minecraft-pixel-skin` Skill 的制作流程、工具、模板目录和运行所需的指南、参考素材。

## 冻结模板

A/B/C 的正式版本均为 `1.0.0`。发布时保留以下内容：

- `surfaces` 像素矩阵与 `palette` 配色；
- `protected_visible` 保护区与 `allowed_alpha`；
- 已批准状态、版本号、候选来源哈希；
- 像素定义哈希与保护区哈希；
- 原历史验证范围，包括未进行游戏内验证这一记录。

正式制作读取 `assets/templates/index.json` 指向的冻结版本。原 `template.json` 为历史候选，保留用于来源追溯，不改为正式模板。

## 历史记录的处理

发布副本从历史确认元数据中移除了私人称谓、聊天原句和本机绝对路径。候选来源路径改为仓库内相对路径；未公开的旧审阅文件仅保留 `A-B-C-v07/文件名` 形式的历史名称及原有哈希。

`A-B-C-v07` 旧审阅文件未包含在仓库中，记录中的历史名称不是可下载链接，也不属于运行所需资源。原始本地 Skill 没有被这次发布修改。

冻结文件的整体文件哈希会因元数据脱敏而改变；像素定义哈希、保护区哈希和历史候选文件哈希保持不变。不能把整文件哈希变化误认为像素结构变化。

## 参考素材

`assets/sources/` 的指南图和小璃精确提取样本供现有工具复现、检查像素与追溯来源；`assets/fixtures/` 的指南发型为独立演示数据，不能直接作为当前角色的发型要求。

原有参考文件和第三方署名保持不变。浏览器审阅效果不会成为 Minecraft 静态皮肤新增的动画或几何功能。
